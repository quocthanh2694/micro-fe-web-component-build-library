## Pj1
- `shop` Shopping center
- `container` Container (also is a Landing page)

## Running

```bash
yarn
```

```bash
yarn start
```

Lerna will start all your projects parallelly and open your browser.

- http://localhost:3000/ (container)
- http://localhost:3001/ (shop)
